## Flow problems

### Ford–Fulkerson method

Let $G(V,E)$ be a graph, and for each edge from $u$ to $v$, let $c(u,v)$ be the capacity and $f(u,v)$ be the flow. The following is maintained:

Capacity constraints: $f(u,v)\le c(u,v)$

Skew symmetry: $f(u,v)=-f(v,u)$

Flow conservation:  $u\not=s,t\Rightarrow\sum_{v\in V}f(u,v)=0$

and $f=\sum_{u\in V}f(s,u)=\sum_{u\in V}f(u,t)$

Define residual network $G_f(V,E_f)$ to be network with residual capacity $c_f(u,v)=c(u,v)-f(u,v)$ and no flow. 

For each step, find a path from $s$ to $t$ s.t. $c_f(u,v)>0$ for all edges $(u,v)$. Then update $f(u,v),f(v,u)$. The path is defined as the augumenting path of graph.

### EK-algorithm

EK: find augumenting path by bfs. 

The length of shortest augumenting path increases motonotically.

- proof: in residual network, suppose the bottleneck edge in augumenting path is $(u,v)$ with $d_v=d_u+1$, then replace $u\to v$ by $v\to u$, but $d_v$ cannot be decreased since in bfs tree, the non-tree edge incident to $v$ only comes from depth $d_v-1,d_v$ or $d_v+1$.

Each edge can be the bottleneck at most $\frac{n}{2}$ times.

- proof: suppose $u\to v$ is the bottleneck edge, so $d_v=d_u+1$, once the edge is reversed back, it means $d_u\leftarrow d_v+1$, so $d_u$ is increased by $2$. $d_u\le n$, so the edge can only be the bottleneck in $\le \frac{n}{2}$ times.

So, the number of path is $O(mn)$ and time complexity is $O(m^2n)$

### Min-cut

Suppose there are two disjoint set $S,T$ where $s\in S,t\in T,S\cup T=V$, the cut is defined as the set of edges $\{(u,v):u\in S,v\in T\}$.

It is well-known that max-flow = min-cut:

flow $\le$ min-cut: for any cut $S,T$, flow = flows from $S$ to $T$ - flows from $T$ to $S$, where the former $\le$ the cut from $S$ to $T$.

max-flow is a cut: If $f$ is a max-flow, then there are no augumenting paths from $s$ to $t$. So the flow is also a cut.

### Minimum cost flow

Given a network with cost $a$, find minimum $\sum_{(u,v)\in E}a(u,v)f(u,v)$ with condition $d=\sum_{v\in V}f(s,v)=\sum_{v\in V}f(v,t)$ for some $d$.

Cycle canceling: find a negative cost cycle repeatedly, then send a flow through that cycle. Note that there is no concept of source or sink in cycle canceling, so add $(t,s)$ with cost of $-\infty$ and capacity of $k$.

#### Min cost flow is a convex

The algorithm repeatedly finds the negatively largest cycle then cancels it, so the difference (length of cycle) decreases.
