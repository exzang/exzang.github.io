### Edge BiConnected Components (EBC)

Given an undirected connected graph $G=(V,E)$, let $E'$ be the set of [bridges](https://en.wikipedia.org/wiki/Bridge_(graph_theory)), then the connected components in $G'=(V,E \backslash E')$ are EBCs.  

Proof:  
-  ($\Rightarrow$) if $u,v$ are connected in $G'$, then there exists path from $u\to v$ s.t. all edges are not bridge, then deleting any edge does not affect connectivity, so $u,v$ are biconnected. 

-  ($\Leftarrow$) if $u,v$ are not connected in $G'$, then there exists at least one bridge for all paths from $u\to v$, so $u,v$ are not biconnected.

So EBCs are a partition of vertices.

### Vertex Biconnected Components (VBC)

1. for any two vertices $u,v$ in vertex biconnected graph $G$, there exists a simple cycle that contains $u,v$.

2. for any vertex $u$ and edge $e$, there exists a simple cycle that contains $u$ and $e$.  

    - proof: create newnode $c$, then split $e=(a,b)$ into $(a,c),(c,b)$, the new graph is vertice-biconnected, and (1) completes the proof.

3. For any two edges $e_1,e_2$, there exists a simple cycle that contains $e_1,e_2$.

4. For any two distinct vertices $x,y$ and edge $e$, there exists a simple path $x\to y$ that contains $e$.

    - proof: suppose $e=(u,v)$, connect $x,y$ to a new vertex $t$, the resulted graph is biconnected, and there exsits a cycle containing $t$ and $e$ by (2). Then $x\to u\to v\to y$ is the path that contains $e$.

5. for any two edges $e_1,e_2$ in graph $G$, $e_1,e_2$ belong to same VBC iff they are contained by a simple cycle.

    - proof 
    $\Rightarrow$: (3) is sufficient.  
    $\Leftarrow$: If $e_1,e_2$ are contained by a simple cylce, then all vertices on the cycle belong to same VBC. 

So VBCs are a partition of edges.

### Dominator Tree

#### Definition
Given a directed graph $G=(V,E)$ and a sourse vertex $S$, $v$ dominates $u \ ($denote as $v \ \text{dom} \ u)$ if all the paths $S\to u$ pass through $v$. 

1. By definition, $S$ dominates all other vertices in graph.
2. $u \ \text{dom} \ v,v \ \text{dom} \ w\to u \ \text{dom} \ w$
3. $u \ \text{dom} \ v,v \ \text{dom} \ u\to u=v$
4. Suppose $u\not=v\not=w$, $u \ \text{dom} \ w$, $v \ \text{dom} \ w$, then $u \ \text{dom} \ v$ or $v \ \text{dom} \ u$.

Define $\text{idom}(u)$ as the dominator of $u$ that is dominated by all other dominators of $u$. By (1) and (4), $\text{idom}(u)$ is well-defined. 

If we build edges $(\text{idom}(u),u)$ for all $u\in V$, then the resulting graph is a tree by (3), and the tree is defined as the **dominator tree** of $G$.


#### Lengauer–Tarjan Algorithm

First, do a dfs (starting from $S$) on $G$, and we call $u<v$ only if $\text{dfn}_u<\text{dfn}_v$. Let the dfs tree be $T$.

Let $\text{sdom}(u)=\min\{v:\exists v\to v_1\to \cdots v_k=u, \forall 1\le i\le k-1, v_i > u\}$ i.e. the minimal $v$ s.t. there exists a path that all vertices on path (except $u,v$) are greater than $u$

1. For any directed edge $(x,y)\in G$, either $y$ is a descendant of $x$, or $y<x$.
2. For any $u,v\in V$ s.t. $u\le v$, then every path $u\to v$ must contain common ancestor of $u,v$ (note that it may not be LCA) in $T$. 
    - proof: let $u=v_0\to v_1\to\cdots\to v_k\to v_{k+1}=v$ be the path. Suppose the minimal vertice is $v_j$, and the $i$ is the minimal index s.t. $i>j$ and $v_i$ is not the descendant of $v_j$. So $v_i < v_{i-1}$ by (1) and $v_i$ is not in the subtree of $v_j$, then the fact $v_i < v_j$ contradicts the assumption. Thus, $v_i$ is the descendant of $v_j$ for all $i>j$. By assumption, $v_j\le u\le v$, so $u$ is also the descendant of $v_j$.
3. $\text{idom}(u)$ must be an ancestor of $u$ in $T$
4. $\text{sdom}(u)<u$
    - proof: let $p$ be the parent of $u$ in $T$, $\text{sdom}(u)\le p<u$ by definition.
5. $\text{sdom}(u)$ must be an ancestor of $u$ in $T$
    - proof: suppose $v=\text{sdom}(u)$, the path $v\to u$ contains an ancestor of $u$ by (2), but all vertices on path except $u,v$ are greater than $u$ by definition, so $v$ is an ancestor of $u$.
6. $\text{idom}(u)$ must be an ancestor of $\text{sdom}(u)$
    - proof: by definition, all vertices on the path $\text{sdom}(u)\to u$ are greater than $u$, so if $v$ is an ancestor of $u$ s.t. $\text{sdom}(u)<v<u$, then $v$ cannot dominate $u$.
