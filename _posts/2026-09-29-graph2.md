## Planar Graph

a planar graph is a graph that can be embedded in the plane.

#### Kuratowski's theorem:

A graph is planar iff it has no subgraph homeomorphic to $K_{3,3}$ or $K_5$.

#### Euler's formula:

$|V|-|E|+|F|=2$ for a connected planar graph

$|V|=$ number of vertices, $|E|=$ number of edges, $|F|=$ number of faces.

Proof by induction:

Base case: tree, $E=V-1$ and $F=1$  
Induction: if the graph is not a tree, remove an edge on cycle, it reduces $E$ and $F$ by $1$, so the value is unchanged.

Corollary $|E|\le 3|V|-6$

## Series-Parallel Graph

Definition: see [Wiki](https://en.wikipedia.org/wiki/Series%E2%80%93parallel_graph#Second_definition)

### Generalized Series-Parallel Graph

A graph is an GSP-graph, if it may be turned into a single vertex by a sequence of the following operations:
    1. Replacement of a pair of parallel edges with a single edge
    2. Replacement of a pair of edges incident to a vertex of degree $2$ with a single edge
    3. Delete a vertex with degree $1$.

Properties:

1. $m\le 2n$ and the graph is planar.
2. It has no subgraph homeomorphic to $K_4$.


In these operations, the value of $m-n$ is unchanged, and $3n\le 2m$ after taking these operations on any arbitrary graph. So, if $m-n\le k$ for a small value $k$, then $n\le 3k,m\le 2k$ after taking a sequence of operations.

#### Sample 1

[Statement](https://codeforces.com/problemset/problem/2164/F2)

For any $u$, if the order of $p$ is known for all vertices on path $1\to fa_u$, then insert $u$ into sorted $p$ since we know the rank of $p_u$ on path $1\to u$. Let the predecessor be $x$ and the successor be $y$, link $(x,u),(u,y)$. Then the problem is reduced to count the number of topological orderings, and it's hard.

Observe that the linkage $x\to u\to y$ is actually the inverse of operation 2 in GSP graph. Also, when deleting $(x,u)$ and $(u,y)$, the edge $(x,y)$ exists since $x$ is predecessor of $y$ after deleting $u$. So we only need to take operation (1) and (2). Denote $f$ as the number of orderings, and $c$ as the number of vertices on edge $u\to v$ :
(1) $f_1\leftarrow f_1\times f_2\times  \binom {c_1+c_2} {c_1},c_1\leftarrow c_1+c_2$
(2) $f_{new}\leftarrow f_1\times f_2,c_{new}\leftarrow c_1+c_2+1$

Note that the source is $0$ and the target is $n+1$, in case $u$ has no predecessor or successor.
